# UX audit, 2026-11-03 (web 1440×900 and phone 390×844)

Local production build against the live DB, Playwright, four review lenses:
**UX flow**, **visual design**, **mobile-first**, **first-time visitor**. Findings are
merged and ranked; the tag after each item says which lenses raised it.
Screenshots: `/mnt/project-files/ux-audit-2026-11-03/` (project files, not in git).

The one-line verdict: the data and features are strong, but the screen shows
everything at once. A newcomer sees a cloud of overlapping pins and a panel with
twelve blocks, and the main job (find my film, see its places, walk them) is buried.

## Fixed in the audit PR

1. **Desktop place card ran off the top of the screen.** It was anchored to the
   bottom with no height cap and `overflow: hidden`, so a tall card (any place with
   a voice guide and photos) lost its title and close button and could not scroll.
   Now capped to the viewport and scrollable. *(UX, newcomer)*
2. **Desktop place card covered zoom, locate and layers.** It now sits left of the
   map buttons, like the section sheet already did. *(UX)*
3. **A failed "place today" photo showed raw alt text in a broken box.** It now
   falls back to the "Place photo unavailable" placeholder. *(visual)*
4. **Internal status shown to users:** "Scene matching unavailable / failed" became
   "No film frame for this place yet" / "Couldn't load the film frame". *(newcomer)*
5. **Search placeholder was cut off** ("…or a cit"). Now "Film, series, book or city". *(visual, mobile)*
